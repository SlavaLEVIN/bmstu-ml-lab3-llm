## Запуск в VS Code

Открой эту папку как проект. Создай виртуальное окружение Python 3.13+ и установи зависимости:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Выбери это окружение как ядро тетради. Для просмотра имеющихся результатов достаточно выполнить **analyze_answers.ipynb**: она не вызывает модели.

Для новых запросов скопируй `.env.example` в `.env` и заполни `GIGACHAT_CREDENTIALS` и `LLM_GATE_API_KEY`. Выполни **collect_api_answers.ipynb**. Группы GigaChat и GPT запускаются раздельно; настрой сеть для соответствующего провайдера. Готовые полные ответы пропускаются. Ключи `.env` не отправляются в Git.

Локальная модель запускается по [инструкции Colab](docs/colab_setup.md). Для уже полученных ответов повторный запуск генерации не нужен.

- GPT: завершены **450/450** запросов классификации (150 × 0/5/20-shot) и **18/18** новых контрольных задач. Построены LogReg/GaussianNB, CI, графики и доступные проверки гипотез. Остальные модели в дополнительные результаты пока не включены.
- В Colab подготовлен пакет дополнительных прогонов Qwen и T-lite 8B. Четвёртой модели в итогах пока нет. Для GigaChat нужна доступная из РФ сеть; для Colab — рабочее соединение с T4.

По PDF нужны **четыре модели, две российские**. T-lite — российская открытая модель; замену указанного в таблице Яндекса следует согласовать. Гипотезы зафиксированы отдельным коммитом после пилота: это не предварительная регистрация начального эксперимента задним числом. Авторство задач студентом, заимствованные источники, две человеческие оценки и окончательные авторские выводы требуют завершения.

Для дополнительных API-тестов из корня проекта:

```bash
python run_remaining_api.py gigachat
# GPT уже закончен; повторный запуск пропускает полные ответы:
python run_remaining_api.py gpt
```

Для дополнительных локальных тестов открой `run_remaining_colab.ipynb` в Colab и загрузи `colab_inputs.zip`. Скачанный `colab_experiments.jsonl` положи в `logs/`, затем выполни аналитическую тетрадь. Она не обращается к API.

В CSV переносы ответа представлены буквальными `\n`, одна запись занимает одну строку. Исходный текст и код — в JSONL. Оценки качества в отчёте предварительные до человеческого подтверждения. Справочная стоимость GPT отличается от фактического списания посредника; у GigaChat Ultra платный тариф не опубликован. Локальные модели сравниваются по времени и памяти GPU.
