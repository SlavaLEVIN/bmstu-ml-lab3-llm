Учебный эксперимент: GigaChat-3-Ultra и GPT-6.1 Sol через API, Qwen3-4B-Instruct-2507 на Tesla T4 в Google Colab.

## Запуск в VS Code

Открой эту папку как проект. Создай виртуальное окружение Python 3.13+ и установи зависимости:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Выбери это окружение как ядро тетради. Для просмотра имеющихся результатов достаточно выполнить **analyze_answers.ipynb**: она не вызывает модели.

Для новых запросов скопируй `.env.example` в `.env` и заполни `GIGACHAT_CREDENTIALS` и `LLM_GATE_API_KEY`. Выполни **collect_api_answers.ipynb**. Группы GigaChat и GPT запускаются раздельно; настрой сеть для соответствующего провайдера. Готовые полные ответы пропускаются. Ключи `.env` не отправляются в Git.

Локальная модель запускается по [инструкции Colab](docs/colab_setup.md). Для уже полученных ответов повторный запуск генерации не нужен.

## Состояние работы

Получено **108 из 108** ответов трёх моделей. Автоматически проверяются A/B/E: **45 ответов**. В B это только метка, обоснование оценивается отдельно. Листы ручной проверки пока пустые. Для C/D нужны два независимых проверяющих, не видящих названий моделей. F также требует содержательной проверки. Код D следует запускать без исправлений и проверять методологию.

Подготовлены классические baselines для E на 150 строках, но предсказания LLM в режимах 0/5/20-shot ещё не получены. Гипотезы, прогноз и самостоятельный отчёт не завершены. Текущий прогон — предварительный; начальный коммит не является предварительной регистрацией гипотез задним числом.

По PDF требуется **минимум четыре модели, две российские**. Сейчас используется одна российская, одна большая зарубежная и одна маленькая открытая модель. Необходимо добавить вторую российскую модель либо согласовать сокращённый состав с преподавателем. Авторство части задач, источники и эталоны требуют проверки; соответствующие пометки сохранены в `data/questions.csv`.

В CSV переносы строк ответа записаны как буквальные `\n`, чтобы одна запись занимала одну строку. Для работы с исходным текстом и кодом используй JSONL. Точность в текущем отчёте относится только к проверенным ответам. Стоимость GPT рассчитана по справочному тарифу, часть старых записей даёт диапазон; стоимость GigaChat пока не рассчитана. Для локальной модели записаны время и память GPU.
