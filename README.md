# ЛР 3 — сравнение LLM

Вся работа находится в **[lab3.ipynb](lab3.ipynb)**: запросы GigaChat/GPT, готовые ответы, проверки, статистика и графики.

- **[answers.csv](answers.csv)** — ответы трёх моделей и оценки.
- **data/** — исходные вопросы, журнал ответов, разбиения/эталоны и два листа проверки.
- **[assignment.pdf](assignment.pdf)** — задание.

Открой тетрадь в VS Code и выполни ячейки сверху вниз. При первом запуске при необходимости сними комментарий со строки установки зависимостей в первой кодовой ячейке. По умолчанию используются готовые результаты, API не вызываются. Для новых запросов заполни `.env` по `.env.example` и включи нужный флаг в начале тетради. Группы GigaChat и GPT запускаются раздельно.

**Qwen 4B запускалась в Google Colab. Все 36 её ответов уже включены в журнал; повторно загружать модель не нужно.**

Получены 108 основных ответов и дополнительные 450 классификаций/18 контрольных ответов GPT. Первый лист проверки пока размечен ИИ, второй пуст. Недостающие по заданию проверки и ограничения указаны в тетради.
