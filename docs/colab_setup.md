# Qwen 4B в Google Colab

1. Открой https://colab.research.google.com и загрузи **run_local_model_colab.ipynb**.
2. Выбери **Среда выполнения → Сменить среду выполнения → T4 GPU**. Бесплатный GPU предоставляется при наличии ресурсов.
3. Выполняй ячейки сверху вниз. Разреши подключение Google Диска и выбери **data/questions.csv** с компьютера. Можно выбрать ровно один файл с другим именем: ячейка сохранит его как датасет.
4. После загрузки весов запусти **«Весь датасет»**. Готовые ответы сохраняются в `Мой диск/Lab3_4/answers_local.jsonl` после каждого вопроса. При обрыве повтори ячейки: вопросы с полными ответами пропускаются. Этот путь на Диске сохранён для продолжения существующего прогона.
5. Последняя ячейка скачает **local_responses.jsonl**. Перенеси его в **logs/** проекта, заменив предыдущую версию, если она есть.
6. В VS Code открой корень проекта и выполни **collect_api_answers.ipynb**, затем **analyze_answers.ipynb**. Готовые API-ответы не запрашиваются повторно. Обновятся **all_answers.csv** и папка **results/**.

Модель: **Qwen/Qwen3-4B-Instruct-2507**, загрузка в FP16, жадная генерация, seed=42. API-ключ не требуется. Промпты совпадают с API-тетрадью. Журнал содержит время, токены, ревизию, версии библиотек, GPU и пиковую занятую память. Время загрузки весов записано отдельно. При достижении лимита увеличь `MAX_TOKENS` для нужного типа и повтори прогон.

Справка: https://huggingface.co/Qwen/Qwen3-4B-Instruct-2507 и https://research.google.com/colaboratory/faq.html.

## Дополнительные эксперименты

Основные 36 ответов Qwen уже получены. Для оставшейся части открой **run_remaining_colab.ipynb** на T4 и выполни единственную кодовую ячейку, выбрав **colab_inputs.zip** из корня проекта. В архиве нет API-ключей. Скрипт запускает 450 E и 18 контрольных задач Qwen, затем 36 основных и 468 дополнительных задач T-lite 8B в NF4. Результаты дописываются после каждого ответа в `Мой диск/Lab3_4/colab_experiments.jsonl`; завершённые запросы при повторном запуске пропускаются.

В конце скачивается **colab_results.zip**. Извлеки только **colab_experiments.jsonl** в **logs/** проекта и выполни **analyze_answers.ipynb**. Новая модель появится в сводке только после реальных ответов. Для её B/C/D/F также потребуется разметка; оценки автоматически не выдумываются.

Если соединение оборвалось, переподключись к той же среде. Если Colab создал новую среду, заново выполни загрузочную ячейку и выбери архив; журнал на Диске позволит продолжить. Не монтируй Диск в `/content`: правильный путь — `/content/drive`. Предупреждение об отсутствии HF_TOKEN не мешает скачиванию публичных весов.
