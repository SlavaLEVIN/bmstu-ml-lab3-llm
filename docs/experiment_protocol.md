# Протокол дополнительных экспериментов

Этот протокол составлен после просмотра предварительного прогона (108 ответов). Это не предварительная регистрация исходного прогона и не прогноз, якобы сделанный до него. Прогнозы предложены ассистентом и требуют принятия авторами. Новые ответы на отдельные контрольные формулировки и 150 строк классификации на момент фиксации не получены.

Три гипотезы из разных групп:

- **H3, группа 1:** на задачах с недостающими данными численный выдуманный ответ встречается чаще корректного указания недостатка данных. Прогноз для новых 6 HF-задач: **не подтвердится**. Считаем долю содержательно правильных отказов; отказ — правильный ответ, а не ошибка API. Предварительная разметка ИИ должна быть подтверждена человеком.
- **H5, группа 2:** отставание маленькой Qwen 4B от GigaChat/GPT сильнее на расчётных задачах, чем на концептуальных. Прогноз: **подтвердится**. На новых 6 HA и 6 HB сравниваем (средняя accuracy больших − accuracy Qwen) для A и B; 95% CI разности разрывов — независимый bootstrap задач внутри A/B, 1000 итераций, seed=42. T-lite, если запущен, показывается отдельно как российская открытая 8B модель, не смешивается с большими.
- **H12, группа 4:** при 5 примерах LLM не хуже LogReg, при 20 — хуже. Прогноз: **не подтвердится**. Один фиксированный test из 150 строк; 5-shot является подмножеством 20-shot, оба не пересекаются с test. Метрики: F1 класса 0, balanced accuracy и accuracy константного предсказания. Для разности LLM − LogReg — парный bootstrap 1000, seed=42. Не объявляем эквивалентность только из-за отсутствия значимости; порог неухудшения заранее не задан, поэтому формулировку «не хуже» оцениваем описательно и с CI.

Веса и настройки: GigaChat-3-Ultra, gpt-6.1-sol, Qwen/Qwen3-4B-Instruct-2507. Для второй российской модели подготовлен t-tech/T-lite-it-2.1 (8B, 4-битная NF4 на T4); это замена предложенному в PDF Яндексу, которую следует согласовать с преподавателем. Сравнение с Яндексом не заявляется.

Все модели получают одинаковые пользовательские промпты. Системная инструкция совпадает с основным прогоном. GigaChat: temperature=0.0001; GPT: reasoning_effort=low; открытые модели: do_sample=False. История между запросами не переносится. Эталон test не передаётся LLM, эталоны HA/HB/HF вырезаются из запросов. Программы D из пилота не исправляются.

API-прогон GPT ограничен дополнительным бюджетом $1 по справочному тарифу $2/$10 за миллион входных/выходных токенов. Пополнений и подключения платных услуг не происходит. Ошибки и незавершённые группы сохраняются и не заменяются выдуманными предсказаниями.

Файлы промптов и разбиений фиксируются данным коммитом до получения новых результатов. Авторство сгенерированных ассистентом контрольных задач не приписывается студенту.
